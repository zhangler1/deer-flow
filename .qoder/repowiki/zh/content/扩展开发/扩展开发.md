## 工具扩展
在 deer-flow 系统中，工具（Tool）是执行特定功能的组件。开发者可以通过在 `src/tools/` 目录下创建新的工具类来扩展系统功能。每个工具类需要定义输入输出模型、实现业务逻辑，并通过装饰器或工厂函数进行注册。

### 工具类结构
工具类通常继承自 `BaseTool`，并实现 `_run` 和 `_arun` 方法。`_run` 方法用于同步执行，而 `_arun` 方法用于异步执行。工具类还需要定义 `name`、`description` 和 `args_schema` 属性，以便系统识别和调用。

## 智能体扩展
智能体（Agent）是系统中的决策和执行单元。开发者可以通过在 `src/agents/` 目录下创建新的智能体类来扩展系统功能。智能体的行为由其提示词（Prompt）和工具集（Tool）共同决定。

### 提示词设计
智能体的提示词定义了其行为模式和任务目标。开发者可以参考 `src/prompts/template.py` 中的模板来设计新的提示词。提示词通常包含角色定义、任务描述、输出格式要求和约束条件。

## 工作流图扩展
工作流图（Workflow Graph）定义了智能体、工具和节点之间的执行流程。开发者可以通过修改 `src/graph/builder.py` 文件来扩展或修改工作流图。

### 节点与边的定义
在 `builder.py` 中，使用 `StateGraph` 来定义节点（Node）和边（Edge）。节点对应于具体的执行函数，边定义了节点之间的跳转逻辑。通过 `add_node` 和 `add_edge` 方法可以添加新的节点和边。

## 完整示例：创建自定义搜索工具
本示例将指导开发者创建一个自定义搜索工具，该工具可以集成到 deer-flow 系统中。

### 步骤1：创建工具类
在 `src/tools/` 目录下创建 `custom_search.py` 文件，并定义 `CustomSearchTool` 类。

```python
from langchain_core.tools import BaseTool
from pydantic import BaseModel, Field
from typing import Dict, Any, Optional
from src.utils.enhanced_logger import get_enhanced_logger

enhanced_logger = get_enhanced_logger('tools.custom_search')

class CustomSearchInput(BaseModel):
    """自定义搜索工具的输入模型"""
    query: str = Field(description="搜索查询字符串")
    repository_id: Optional[str] = Field(default=None, description="用于搜索的仓库ID")

class CustomSearchTool(BaseTool):
    name: str = "web_search"
    description: str = "搜索网络信息。输入应该是搜索查询字符串。"
    api_url: str = Field(default="")
    api_key: str = Field(default="")
    max_results: int = Field(default=10)
    repository_id: str = Field(default="aggregation_search")

    def __init__(self, **kwargs):
        super().__init__(**kwargs)
        self.args_schema = CustomSearchInput
        self.api_url = "https://api.example.com/search"
        self.api_key = "your-api-key"

    def _run(self, query: str, repository_id: Optional[str] = None) -> Dict[str, Any]:
        # 实现搜索逻辑
        enhanced_logger.logger.info(f"执行搜索: {query}")
        return {"results": [], "query": query}

    async def _arun(self, query: str, repository_id: Optional[str] = None) -> Dict[str, Any]:
        return self._run(query, repository_id)
```

### 步骤2：注册工具
在 `src/tools/__init__.py` 中导入并注册新工具。

```python
from .custom_search import CustomSearchTool

__all__ = ["CustomSearchTool"]
```
