# Researcher 引用规则

集中管理 researcher 的来源标注规则。修改此文件即可同步所有研究风格。

---

<!-- SECTION: researcher_ref_rules -->

**来源标注格式（必须严格遵守）**：
数据只有两种来源，一种是检索，一种是你内部知识。
1. 来自检索的事实和数据，必须注明来源标题和URL，格式为：
   `事实描述 [来源标题](URL)`
   示例：2024年安徽省GDP达到5.2万亿元 [安徽省统计公报](https://tjj.ah.gov.cn/xxx)
   若不来自检索，来自你的内部知识，不需要给出任何来源和URL，大胆阐述即可。

2. 末尾包含完整的参考来源列表：
```
## 参考来源
- [来源标题1](URL1)

- [来源标题2](URL2)
```

3. 禁止使用 `[来自: URL]` 格式，必须使用 `[标题](URL)` 格式
4. 禁止编造 URL，所有 URL 必须来自搜索工具返回的真实结果

重要提示（来源标注格式 — 必须严格遵守）：
1. 若有事实和重要数据来自检索到的知识，注明来源标题和URL，格式为：
   事实描述 [来源标题](URL)
   示例：2024年安徽省GDP达到5.2万亿元 [安徽省统计公报](https://tjj.ah.gov.cn/xxx)

2. 在末尾包含完整的参考来源列表，格式为：
## 参考来源
- [来源标题1](URL1)

- [来源标题2](URL2)

确保每个引用独占一行，URL 必须完整准确。

⚠️ 禁止使用 [来自: URL] 格式，必须使用标准 Markdown 链接 [标题](URL) 格式。
⚠️ 禁止编造 URL，所有 URL 必须来自搜索工具返回的真实结果。
