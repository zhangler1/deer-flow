## 简介

DeerFlow是一个社区驱动的深度研究框架，结合了语言模型与专门工具（如网络搜索、爬虫和Python代码执行）来完成复杂的任务。本快速入门指南将帮助您在最短时间内搭建并运行DeerFlow系统，让您能够快速体验其核心功能。

## 系统要求

在开始之前，请确保您的系统满足以下最低要求：

- **Python**: 版本 3.12+
- **Node.js**: 版本 22+
- **操作系统**: 支持 macOS、Linux 和 Windows

## 环境准备

### 安装推荐工具

为了简化Python环境和依赖管理，我们推荐使用以下工具：

#### 1. uv (Python包管理器)
```bash
# 安装uv
curl -LsSf https://astral.sh/uv/install.sh | sh

# 验证安装
uv --version
```

#### 2. nvm (Node.js版本管理器)
```bash
# 安装nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.0/install.sh | bash

# 重新加载shell配置
source ~/.bashrc

# 安装Node.js 22+
nvm install 22
nvm use 22
```

#### 3. pnpm (包管理器)
```bash
# 安装pnpm
npm install -g pnpm

# 验证安装
pnpm --version
```

## 项目克隆与初始化

### 克隆仓库

```bash
# 克隆DeerFlow仓库
git clone https://github.com/bytedance/deer-flow.git
cd deer-flow
```

### 初始化项目结构

```bash
# 创建虚拟环境并安装Python依赖
uv sync

# 复制示例配置文件
cp .env.example .env
cp conf.yaml.example conf.yaml
```

## 依赖安装

### 后端依赖安装

#### 使用uv自动安装
```bash
# 自动创建虚拟环境并安装所有依赖
uv sync
```

#### 手动安装方式
```bash
# 创建虚拟环境
uv venv

# 激活虚拟环境
source .venv/bin/activate  # Linux/macOS
# .venv\Scripts\activate  # Windows

# 安装依赖
uv pip install -r requirements.txt
```

### 前端依赖安装

#### 使用pnpm安装
```bash
# 进入web目录
cd web

# 安装前端依赖
pnpm install

# 返回项目根目录
cd ..
```

### 可选组件安装

#### Marp CLI (用于PPT生成)
```bash
# macOS
brew install marp-cli

# 或者使用npm
npm install -g @marp-team/marp-cli
```

## 配置文件设置

### 环境变量配置 (.env)

复制并编辑环境变量配置文件：

```bash
# 编辑.env文件
nano .env
```

#### 基本配置项

```bash
# 应用设置
DEBUG=True
APP_ENV=development
AGENT_RECURSION_LIMIT=30

# CORS设置
ALLOWED_ORIGINS=http://localhost:3000

# 搜索引擎配置
SEARCH_API=tavily
TAVILY_API_KEY=tvly-xxx

# 可选：其他搜索引擎
# SEARCH_API=duckduckgo
# SEARCH_API=brave_search
# BRAVE_SEARCH_API_KEY=xxx
```

#### API密钥配置

获取必要的API密钥：

1. **Tavily API Key**: 访问 https://app.tavily.com/home 注册
2. **Brave Search API Key**: 访问 https://brave.com/search/api/ 注册
3. **Volcengine TTS**: 如果需要语音功能，请添加您的TTS凭据

#### 高级配置选项

```bash
# 启用MCP服务器配置（生产环境需谨慎）
ENABLE_MCP_SERVER_CONFIGURATION=false

# 启用Python REPL（生产环境需谨慎）
ENABLE_PYTHON_REPL=false

# LangSmith追踪配置
# LANGSMITH_TRACING=true
# LANGSMITH_ENDPOINT="https://api.smith.langchain.com"
# LANGSMITH_API_KEY="xxx"
# LANGSMITH_PROJECT="xxx"
```

### LLM配置 (conf.yaml)

编辑LLM配置文件：

```bash
# 编辑conf.yaml
nano conf.yaml
```

#### 基础模型配置

```yaml
BASIC_MODEL:
  base_url: https://ark.cn-beijing.volces.com/api/v3
  model: "doubao-1-5-pro-32k-250115"
  api_key: xxxx
  max_retries: 3
  verify_ssl: false  # 如果使用自签名证书
```

#### 可选推理模型配置

```yaml
# 推理模型配置（可选）
REASONING_MODEL:
  base_url: https://ark.cn-beijing.volces.com/api/v3
  model: "doubao-1-5-thinking-pro-m-250428"
  api_key: xxxx
  max_retries: 3
```

#### 搜索引擎配置

```yaml
SEARCH_ENGINE:
  engine: tavily
  include_domains:
    - example.com
    - trusted-news.com
    - reliable-source.org
    - gov.cn
    - edu.cn
  exclude_domains:
    - example.com
```

## 服务启动

### 方法一：使用Bootstrap脚本

```bash
# 开发模式启动（同时启动前后端）
./bootstrap.sh -d

# 生产模式启动（仅启动后端）
./bootstrap.sh
```

### 方法二：手动启动服务

#### 后端服务启动

```bash
# 启动后端服务器
uv run server.py --host 0.0.0.0 --port 8000
```

#### 前端服务启动

```bash
# 进入web目录
cd web

# 开发模式启动
pnpm dev

# 或者生产模式启动
pnpm start
```

### 方法三：使用Docker Compose

```bash
# 构建Docker镜像
docker compose build

# 启动所有服务
docker compose up

# 在后台运行
docker compose up -d
```

## 常见问题排查

### 端口冲突

**问题**: 端口被占用
```bash
# 查看端口占用情况
lsof -i :8000  # 后端端口
lsof -i :3000  # 前端端口

# 杀死占用进程
kill -9 PID_NUMBER
```

**解决方案**: 修改配置文件中的端口号，或停止占用端口的服务。

### 依赖安装失败

**问题**: uv安装失败
```bash
# 清理缓存并重试
uv cache clean
uv sync --force
```

**问题**: pnpm安装失败
```bash
# 清理pnpm缓存
pnpm store prune
pnpm install --force
```

### API密钥问题

**问题**: API调用失败
```bash
# 检查.env文件中的API密钥
cat .env | grep API_KEY

# 验证API密钥有效性
curl -H "Authorization: Bearer YOUR_API_KEY" https://api.example.com/health
```

### 数据库连接问题

**问题**: LangGraph检查点保存失败
```bash
# 检查数据库连接
mongo --uri "mongodb://localhost:27017/"  # MongoDB
psql postgres://localhost:5432/postgres   # PostgreSQL

# 配置检查点
# 在.env文件中添加：
LANGGRAPH_CHECKPOINT_SAVER=true
LANGGRAPH_CHECKPOINT_DB_URL="mongodb://localhost:27017/"
```

### 权限问题

**问题**: 文件权限错误
```bash
# 设置正确的文件权限
chmod +x bootstrap.sh
chmod +x uv_install.sh
chown -R $USER:$USER .
```
