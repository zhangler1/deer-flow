# Reporter 引用规则

集中管理 reporter 的来源标注规则。修改此文件即可同步所有报告风格。

# 来源标注规则（最高优先级，必须严格遵守）

**核心原则：只标注索引中存在的来源，不存在则不标注。**

**规则**：
1. **仅当**某个数据/事实/观点能在引用的URL可以在「全局来源索引」中找到对应 URL 时，才在句末标注 **[(N)](URL)**，否则直接陈述，不需要URL。
2. 来自你自身知识/常识/推理的内容，**直接陈述，不加任何引用标记**
3. N 是纯数字，对应末尾「参考资料」中的序号，完整格式为(N)。
4. 同一来源可多次引用，使用相同序号
5. **绝对禁止编造 URL** — 宁可不标注也不要虚构链接
6. **绝对禁止使用 [^N] 脚注格式** — 必须使用 [(N)](URL) 格式，圆括号包裹序号N并附带完整URL链接

**正确示例**：
```
2024年安徽省GDP达到5.2万亿元[(1)](https://pbc.gov.cn/report)，同比增长5.8%[(2)](https://stats.gov.cn/data)。
长三角地区整体经济协同发展已成为共识。（← 常识，无需标注）
```

**末尾参考资料格式**：
```
**参考资料**

\[1] 央行2024年货币政策执行报告 [https://pbc.gov.cn/report](https://pbc.gov.cn/report)

\[2] 国家统计局2024年数据 [https://stats.gov.cn/data](https://stats.gov.cn/data)
```

<!-- SECTION: reporter_ref_reminder -->

**引用规则（必须严格遵守）**：
- 正文中引用格式：[(N)](对应的URL)，N 为索引中的序号，带圆括号包裹序号。
- 只能引用「全局来源索引」中存在的 URL，绝对禁止编造
- 来自你自身知识，直接陈述不标注
- 同一来源可多次引用，使用相同序号
- 末尾「参考资料」章节格式：[N] [来源标题](URL)
